# Week 4 — Day 1: Python Functions

## Learning Goals

Practice defining and calling Python functions, using parameters and arguments, returning values with `return`, working with default arguments, and combining functions with conditions and loops.

## Topics

- Defining functions with `def` and calling them
- Parameters in function definitions and arguments in function calls
- Returning values with `return`
- The difference between `return` and `print`
- Default and keyword arguments
- Using conditions and loops inside functions

## Exercises

1. `exercise_01_basic_function.py` — Define and call a function with no parameters.
2. `exercise_02_parameters_and_return.py` — Pass arguments and use a returned value.
3. `exercise_03_return_vs_print.py` — Explore the difference between `return` and `print`.
4. `exercise_04_default_arguments.py` — Use default and keyword arguments.
5. `exercise_05_conditions_and_loops.py` — Build a node report using a condition and a loop.

The exercise functions are in `functions.py`, and their automated tests are in `test_functions.py`.

## Run the Exercises

Run each script from this directory:

```bash
python exercise_01_basic_function.py
python exercise_02_parameters_and_return.py
python exercise_03_return_vs_print.py
